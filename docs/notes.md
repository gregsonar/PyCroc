# Заметки разработки: неочевидные готчи

Пополняется по ходу задач (Task 16 плана требует зафиксировать как минимум №1).
Открытые вопросы ручного тестирования — в `tmp/manual-testing-notes.md`
(не в git): отрисовка галочки file_picker, стрелки в формах, защита кодовых
фраз в БД истории.

## croc и subprocess

1. **Прогресс-бар печатается через `\r`, а не `\n`** (croc перерисовывает
   строку). Построчное чтение `readline()` слипает все обновления в одну
   строку до конца передачи. Решение: чтение чанками +
   `split_stream_chunks()` с разделителями `\r\n`/`\r`/`\n`
   ([parser.py](../src/pycroc/core/parser.py)). Нюанс: одиночный `\r` в хвосте
   буфера удерживается — он может оказаться половиной `\r\n`, разрезанного
   границей чанка.
2. **Accept-prompt печатается без перевода строки**: croc выводит
   `Accept 'file' (116 B)? (y/n) ` и блокируется на stdin. Из нарезки по
   разделителям такая строка не выйдет никогда → deadlock auto-accept.
   Решение: `CrocRunner._run()` пробует незавершённый остаток буфера на
   `ACCEPT_PROMPT_RE` после каждого чанка.
3. **stdout процесса — `DEVNULL`, не `PIPE`**: без `--stdout` croc туда не
   пишет, а нечитаемый `PIPE` при заполнении буфера — потенциальный deadlock.
4. **У ошибок croc нет единого префикса** между версиями. `ERROR_RE` ловит
   только `Error`/`error`/`failed to`; остальное покрывает fallback
   `CrocRunner`: ненулевой returncode → `ErrorEvent` из последних
   нераспознанных строк stderr.

## Textual

5. **`Widget._size` — внутренний атрибут** (объект `Size` компоновщика).
   Поле `self._size` в наследнике ломает рендер загадочным
   `'str' object has no attribute 'region'`. Именовать поля специфичнее
   (`_target_size` в OverwriteConflictModal).
6. **`Label.renderable` не существует** (Textual 8) — содержимое в тестах
   читать через `str(label.render())`.
7. **`Button` глушит повторный клик** пока играет его active-эффект (~0.3 с):
   два `pilot.click()` подряд по одной кнопке — второй молча теряется.
   В Pilot-тестах между кликами нужен `await pilot.pause(0.4)`.
8. **Уведомления в тестах** проверяются только через приватный
   `app._notifications` — публичного API перечисления нет.
9. **Worker + `finally` + размонтирование**: если панель удалена посреди
   передачи, `query_one` в finally кидает `NoMatches` (причём `is_mounted`
   ещё `True`, когда дети уже удалены) — финальные UI-обновления оборачивать
   в `try/except NoMatches`, запись в историю делать безусловно.
10. **Кеш меток `Tree`**: `refresh()` не перерисовывает изменённую метку узла
    (см. пункт 1 ручного тестирования — галочки multi-select) — требуется
    точечная инвалидация. *Открыто, чинится при разборе конспекта.*

## Python и типизация

11. **`qrcode.print_ascii` использует `\xa0`** (неразрывный пробел) для
    пустых модулей QR; для mypy нужны стабы `types-qrcode`.
12. **Метод `list` в классе затеняет `builtins.list`** в аннотациях других
    методов того же класса (mypy valid-type) — писать
    `builtins.list[...]` ([history.py](../src/pycroc/storage/history.py)).
13. **`.py`-заглушку нельзя exec-нуть напрямую** (особенно на Windows):
    `CrocRunner` запускает пути с расширением `.py` через `sys.executable`.
