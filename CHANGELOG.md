# Changelog

## 0.2.0 — 2026-09-17 — croc v11 support

Обновление под croc v11 (актуальная версия v11.5.0) и подтяжка зависимостей.

- Поддержка флага отправки `--transport` (auto/derp/relay, croc v11.3):
  прямой WireGuard-транспорт с откатом на DERP и relay. Это выбор отправителя
  (флаг подкоманды `send`), у приёма его нет. Доступен в форме опций и
  профилях (`transport`).
- Stored-передачи (croc v11.1, только send): флаги `--store`,
  `--store-downloads`, `--store-expiration`, `--store-url` — один
  зашифрованный upload обслуживает нескольких получателей по ссылке в течение
  выбранного срока. Доступны в форме опций и профилях.
- Извлечение кодовой фразы под croc v11: v11 убрал строку `Code is: <code>`,
  теперь код виден только в строке-инструкции `croc <code> (code copied to
  clipboard)` и в URL `https://getcroc.com/?code=<code>`. Парсер распознаёт оба
  варианта; без этой правки в обычном сценарии (код генерирует croc)
  пользователь не увидел бы код. UI показывает код один раз (дедуп по значению).
- Парсер stderr снимает ANSI-раскраску (croc v11 «add color»): устойчив к
  цветному выводу, даже если croc запущен под псевдо-TTY. При обычном
  pipe-выводе croc цвет отключает сам. Разбор строки версии уже принимал
  формат v11 (`croc version 11.5.0`, без префикса `v`).
- Зависимости: `textual>=8.2`, `qrcode>=8.0`; dev — `pytest>=8.2`,
  `pytest-asyncio>=0.24`, `ruff>=0.11`, `mypy>=1.13`, `types-qrcode>=8.0`.
- Запланирована поддержка `croc update` из интерфейса — см.
  [docs/plans/croc-self-update-ui.md](docs/plans/croc-self-update-ui.md).

Примечание: сквозная передача через локальный relay проверена на реальном
croc v11.5.0 (`--transport relay`, автогенерируемый код) и на croc v10.2.7.

## 0.1.0 — 2026-07-18 — initial release

Первый работоспособный выпуск.

- TUI-приложение `pycroc` на Textual: вкладки Send / Receive / History / Settings.
- Обёртка над бинарником croc через asyncio-subprocess: построчный разбор
  stderr (включая перерисовку прогресса через `\r` и accept-prompt без
  перевода строки), отмена передачи, авто-ответ на запрос перезаписи.
- Совместимость с croc v10 (проверено на v10.2.7: порядок глобальных флагов,
  `--ignore-stdin`, новый формат прогресса) с сохранением поддержки
  формата вывода v8/v9.
- Send: multi-select дерево файлов (space/клик), форма всех опций croc,
  QR-код и копирование кодовой фразы, живой прогресс.
- Receive: автодополнение кода из истории, выбор папки назначения,
  модальное подтверждение перезаписи при выключенном `--yes`.
- History: SQLite-история передач, регистронезависимый поиск (Unicode),
  повтор передачи, копирование кода, удаление записей.
- Settings: TOML-профили опций (ручное редактирование поддерживается,
  комментарии сохраняются), выбор активного профиля, путь к бинарнику croc
  с проверкой версии; отсутствие croc не роняет приложение.
- Безопасность: кодовая фраза передаётся croc через переменную окружения
  `CROC_SECRET`, а не через argv — не видна в списке процессов ОС.
